# Working on Astrid App

This repository is the editor's source, not the installation route for creators. To use Astrid, start at [astrid.haus](https://astrid.haus); for manual installation use the [Astrid setup guide](https://github.com/banodoco/astrid-agent/blob/main/docs/getting-started.md).

For a contribution, begin with the [Astrid Dev skill](https://github.com/banodoco/astrid-dev/blob/main/skills/astrid-dev/SKILL.md). Find an existing issue or project before inventing scope; use the product repository's tests and contracts to prove the change. The [contribution workflow](https://github.com/banodoco/astrid-dev/blob/main/docs/contribution-workflow.md) owns review and handoff.

Read the relevant source and nearby tests before editing. For architecture, use [frontend architecture](docs/structure_detail/frontend_architecture.md), [the SDK contracts](docs/video-editor-sdk/README.md), and [code quality](docs/code_quality_audit.md). Do not copy these rules into separate tool-specific instruction files. Preserve user work, source identity, and compatibility; do not publish or deploy without authorization.
